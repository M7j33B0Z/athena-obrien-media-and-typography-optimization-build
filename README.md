# Documentation / Testing Evidence
I tested my website at 250-450px width, 450-750px width, and 750-1080px width, and at various zoom levels in Firefox and Chrome. This also helped me test for layout shift risks. I chose these content breakpoints because they are small, medium, and large, and screens smaller than 250px width are difficult to read/unlikely to be used in this context. I used Silktide to check my accessibility, and Lighthouse to assess the website's performance, file size, and image dimensions. I also assessed my code for errors using WC3 Validation.
